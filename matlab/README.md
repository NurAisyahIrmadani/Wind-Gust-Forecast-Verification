MATLAB Scripts
This directory contains MATLAB scripts used to visualize forecast verification results using Taylor diagrams for wind speed and wind gust.

Scripts
Wind_TD2.m: Taylor diagram for wind speed forecast evaluation.
WindGust_TD2.m: Taylor diagram for wind gust forecast evaluation.

Requirements
MATLAB and the required Taylor diagram toolbox must be available. Check the scripts for their specific toolbox dependencies, input data, and configuration settings before running them.
