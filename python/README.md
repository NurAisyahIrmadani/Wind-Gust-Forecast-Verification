# Python Scripts

This directory contains Python scripts for wind and wind gust forecast verification, time-series visualization, and bias correction using empirical quantile mapping (EQM).

## Scripts

- `03_timeseries_wind_gust_combined.py`: Time-series visualization of wind speed and wind gust.
- `04_skill_wind_gust_combined.py`: Forecast skill evaluation and bootstrap uncertainty analysis.
- `05_eqm_postprocessing_combined.py`: EQM bias correction and leave-one-day-out cross-validation (LODO-CV).
